# nspire-usbshim

The TI-Nspire CX and CX II OS's USB host calls (driver registration, pipes, transfers, hub ports)
as C functions for Ndless programs. The USB libraries of
[gpSP for the TI-Nspire](https://github.com/jadenmcdaniels/lr-gpsp-nspire) share it:
nspire-usbpad, nspire-usbms, nspire-usbaudio and nspire-bt.
